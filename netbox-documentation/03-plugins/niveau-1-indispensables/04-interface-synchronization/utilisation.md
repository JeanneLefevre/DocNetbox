# Interface Synchronization : utilisation pas à pas

1. Corriger d'abord le **Device Type** (menu *Types d'équipement*).
2. Ouvrir la fiche d'un **équipement** de ce type.
3. Ouvrir l'onglet / bouton de **comparaison** (ex. « Interfaces comparison » ; l'intitulé varie selon la version) 🔎.
4. Lire le tableau des **différences** : éléments manquants, en trop, nommés différemment.
5. Cocher les éléments à traiter, puis **créer / renommer / supprimer** selon l'action proposée.
6. Valider.
