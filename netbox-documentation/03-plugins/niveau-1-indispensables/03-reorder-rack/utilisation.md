# Reorder Rack : utilisation pas à pas 🔎

1. Ouvrir la fiche de la **baie** concernée.
2. Cliquer sur le bouton **Reorder** ajouté par le plugin.
3. **Glisser-déposer** les équipements vers leur nouvelle position (U). La hauteur de chaque équipement est respectée.
4. **Enregistrer** : les positions sont mises à jour en une fois.
5. Contrôler les faces avant / arrière et les équipements demi-profondeur.
