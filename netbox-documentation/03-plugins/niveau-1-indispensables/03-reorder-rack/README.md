# NetBox Reorder Rack (rang 3 · niveau 1)

## À quoi ça sert

Dans NetBox standard, déplacer un équipement dans une baie impose d'ouvrir sa fiche et de modifier sa position (U) un par un. Ce plugin permet de **réorganiser par glisser-déposer** directement dans l'élévation de la baie.

## Quand l'utiliser

- Optimiser le remplissage d'une baie.
- Préparer un déménagement ou une réorganisation.
- Corriger rapidement plusieurs positions.

## Conseils

- Travailler **dans une branche** ([Branching](../01-branching/README.md)) pour relire avant d'appliquer.
- Le plugin réorganise **dans** une baie ; pour changer un équipement de baie, passer par sa fiche.
- Complémentaire de [Floorplan](../../niveau-3-specialises/15-floorplan/README.md) (placement de la baie dans la salle).
