# Topology Views : utilisation pas à pas

1. Vérifier que les équipements et les **câbles** existent (*Équipements → Câbles*).
2. Ouvrir le menu **Topology Views**.
3. Appliquer des **filtres** : site, emplacement, rôle, tags. Commencer petit (un site, deux rôles) pour garder un schéma lisible.
4. Cliquer sur **Rechercher / Générer**.
5. **Déplacer** les nœuds pour obtenir une disposition claire. Selon la configuration, les coordonnées peuvent être **sauvegardées**.
6. **Exporter** l'image pour la documentation ou les présentations.
