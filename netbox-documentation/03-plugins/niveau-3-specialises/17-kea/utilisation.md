# Kea : utilisation pas à pas 🔎

1. **Ajouter un serveur** : nom, URL du Control Agent, identifiants éventuels, activation DHCPv4 / DHCPv6, vérification SSL.
2. Ouvrir le serveur ajouté et consulter ses **sous-réseaux** et **baux**.
3. **Rechercher** un bail par adresse IP, MAC ou nom d'hôte.
4. Si les fonctions sont disponibles, créer / supprimer une **réservation**.
5. Comparer avec l'IPAM NetBox.
