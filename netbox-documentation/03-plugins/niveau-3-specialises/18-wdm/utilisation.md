# WDM : utilisation 🔎

> Trame **générale**, à valider avec le README du plugin : les intitulés exacts des menus et objets n'ont pas pu être vérifiés.

1. **Installer** le plugin ([procédure générique](../../installation-generique.md)) et vérifier la compatibilité avec votre version de NetBox.
2. **Choisir le plan de canaux** ITU adapté (DWDM ou CWDM) et le déclarer / sélectionner dans le plugin.
3. **Modéliser les équipements optiques** (multiplexeurs, ROADM) avec leurs ports, comme des équipements NetBox classiques.
4. **Affecter les canaux** (longueurs d'onde) aux liaisons et aux ports concernés.
5. **Contrôler la cohérence** des positions / canaux signalée par le plugin.
6. **Relier** aux circuits et au câblage pour garder une vue de bout en bout.
