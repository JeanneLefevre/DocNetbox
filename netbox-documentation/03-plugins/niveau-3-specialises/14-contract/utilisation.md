# Contract : utilisation pas à pas 🔎

1. Créer la **partie externe** (fournisseur / prestataire).
2. Créer le **contrat** (numéro, dates, durée initiale, renouvellement, montant).
3. Ajouter les **factures** correspondantes.
4. **Affecter** le contrat aux objets concernés (onglet *Contracts* / *Assignments* d'un objet).
5. Suivre les **échéances** via les filtres de date.
