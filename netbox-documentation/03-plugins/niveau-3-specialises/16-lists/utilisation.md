# Lists : utilisation pas à pas 🔎

1. Créer un **token d'API** en lecture seule pour l'outil consommateur.
2. Identifier le point d'accès voulu (adresses IP, préfixes, équipements…) sous `/api/plugins/netbox_lists/`.
3. Appliquer des **filtres** (rôle, tag, site, statut, famille IPv4 / IPv6…) dans l'URL.
4. Configurer l'outil cible (pare-feu, proxy, supervision) pour **lire cette URL** avec le token, à intervalle régulier.
