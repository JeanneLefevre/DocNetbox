# Lifecycle : utilisation pas à pas 🔎

1. Créer les **fournisseurs / constructeurs** (vendors).
2. Saisir les **notices de fin de vie** des types d'équipement (dates publiées par le constructeur).
3. Créer les **contrats de support** (dates et fournisseur).
4. **Affecter** les contrats aux équipements / assets concernés (généralement via les assets du plugin Inventory).
5. Utiliser les **filtres par date** pour lister ce qui arrive à échéance dans 3, 6 ou 12 mois.
