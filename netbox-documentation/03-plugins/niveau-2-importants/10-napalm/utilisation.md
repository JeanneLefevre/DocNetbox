# NAPALM : utilisation pas à pas

1. Ouvrir la fiche d'un équipement.
2. Cliquer sur l'onglet **NAPALM**.
3. Choisir l'information voulue (faits, LLDP, interfaces, etc.).
4. Comparer avec les données de NetBox (ex. voisins LLDP vs câblage documenté, voir [Topology Views](../../niveau-1-indispensables/06-topology-views/README.md)).
