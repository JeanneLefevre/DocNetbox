# NetBox Data Flows (rang 12 · niveau 2)

## À quoi ça sert

Documente les **flux de données entre systèmes et applications** : quelle application parle à quelle autre, sur quel protocole et quels ports. Produit une **matrice de flux**, utile pour les ouvertures de pare-feu, les audits et la sécurité 🔎.

## Notions 🔎

- **Applications** (et rôles d'application).
- **Groupes d'objets réseau** : ensemble d'IP, préfixes, équipements ou VM représentant une source ou une destination.
- **Flux** : source, destination, protocole, ports, statut (actif, planifié, désactivé), description / justification.

## Intérêt

Savoir **pourquoi** une règle de pare-feu existe et pouvoir supprimer celles devenues inutiles. Complète [Security](../11-security/README.md).
