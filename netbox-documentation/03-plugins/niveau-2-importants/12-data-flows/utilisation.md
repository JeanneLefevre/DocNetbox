# Data Flows : utilisation pas à pas 🔎

1. Créer les **applications** (ex. `ERP`, `Base de données ERP`).
2. Créer les **groupes d'objets réseau** : sources (serveurs web) et destinations (serveurs de base de données) à partir des objets existants dans NetBox.
3. Créer le **flux** : application source → application destination, groupes concernés, protocole (TCP / UDP), port(s) (ex. `TCP 5432`), statut **planifié** puis **actif** après mise en œuvre.
4. Exporter ou consulter la **matrice** pour l'équipe sécurité / réseau.
